## 🚀 Features

- **Multi-Core Support**: Native Xray-core and Sing-box engines with one-click switching.
- **Protocols**: VLESS, VMess, Trojan, Shadowsocks, Reality, WireGuard, and Hysteria.
- **Cloudflare Clean IP Scanner**:
  - *Radar Mode*: Live auto-hunting for lowest latency clean IPs without disconnects.
  - *Target Mode*: Batch testing custom IP ranges with up to 100 concurrent workers.
- **Routing Modes**: Global TUN mode (Wintun) and System Proxy (HTTP/SOCKS5) with domain rules.
- **Node & Subscription Management**: Base64/standard import, real HTTP/TCP delay test, duplicate filter.
- **Modern UI**: Flutter-based desktop client with Dark/Light themes and system tray integration.

## 💻 Installation

### Windows (x64)
1. Download `v2raypro-windows-v1.7.3.zip` from the latest [GitHub Releases](https://github.com/iamcloner/v2raypro/releases).
2. Extract the zip archive to your preferred directory.
3. Run `v2raypro.exe` (Run as Administrator if using TUN mode).

### Android Version
> 📱 **Note**: The **Android version** is currently under active development and will be released on the [GitHub Releases](https://github.com/iamcloner/v2raypro/releases) page once ready.
