## 🚀 Возможности

- **Поддержка двух ядер**: Нативная работа с Xray-core и Sing-box с мгновенным переключением.
- **Протоколы**: VLESS, VMess, Trojan, Shadowsocks, Reality, WireGuard и Hysteria.
- **Сканер чистых IP Cloudflare**:
  - *Режим Радар*: Автопоиск IP с минимальной задержкой и бесшовное переключение на лету.
  - *Режим Таргет*: Тестирование заданных диапазонов с параллельностью до 100 потоков.
- **Режимы маршрутизации**: Глобальный TUN (Wintun) и системный прокси (HTTP/SOCKS5) с правилами обхода.
- **Подписки и узлы**: Импорт Base64/стандартных ссылок, замер задержки TCP/HTTP, удаление дубликатов.
- **Современный интерфейс**: Flutter-приложение с темной/светлой темами и работой в системном трее.

## 💻 Установка

### Windows (x64)
1. Скачайте архив `v2raypro-windows-v1.7.3.zip` со страницы [GitHub Releases](https://github.com/iamcloner/v2raypro/releases).
2. Распакуйте архив в удобную папку.
3. Запустите `v2raypro.exe` (для режима TUN запустите от имени администратора).

### Версия для Android
> 📱 **Примечание**: **Android-версия** находится в активной разработке и будет опубликована в [GitHub Releases](https://github.com/iamcloner/v2raypro/releases) по готовности.
