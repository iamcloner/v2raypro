## 🚀 Fonctionnalités

- **Support multi-cœur** : Prise en charge native de Xray-core et Sing-box avec bascule en un clic.
- **Protocoles** : VLESS, VMess, Trojan, Shadowsocks, Reality, WireGuard et Hysteria.
- **Scanner d'IP propres Cloudflare** :
  - *Mode Radar* : Détection automatique des IP à faible latence et bascule à chaud sans coupure.
  - *Mode Cible* : Test par lots de plages IP avec jusqu'à 100 workers simultanés.
- **Modes de routage** : Mode TUN global (Wintun) et Proxy système (HTTP/SOCKS5) avec règles de domaine.
- **Abonnements et nœuds** : Import Base64/standard, test de délai réel HTTP/TCP, suppression des doublons.
- **Interface moderne** : Client Flutter avec thèmes Sombre/Clair et intégration dans la barre des tâches.

## 💻 Installation

### Windows (x64)
1. Téléchargez l'archive `v2raypro-windows-v1.7.3.zip` depuis les [GitHub Releases](https://github.com/iamcloner/v2raypro/releases).
2. Décompressez l'archive dans le dossier de votre choix.
3. Lancez `v2raypro.exe` (exécutez en tant qu'administrateur si vous utilisez le mode TUN).

### Version Android
> 📱 **Remarque** : La **version Android** est en cours de développement et sera publiée sur la page [GitHub Releases](https://github.com/iamcloner/v2raypro/releases).
