## 🚀 Características

- **Soporte multinúcleo**: Motores nativos Xray-core y Sing-box con cambio en un clic.
- **Protocolos**: VLESS, VMess, Trojan, Shadowsocks, Reality, WireGuard y Hysteria.
- **Escáner de IP limpias de Cloudflare**:
  - *Modo Radar*: Búsqueda continua de IP con menor latencia y cambio en caliente sin desconexión.
  - *Modo Objetivo*: Pruebas por lotes con concurrencia ajustable hasta 100 hilos.
- **Modos de enrutamiento**: Modo TUN global (Wintun) y Proxy del sistema (HTTP/SOCKS5) con reglas por dominio.
- **Gestión de nodos y suscripciones**: Importación Base64/estándar, prueba de retardo real HTTP/TCP, eliminación de duplicados.
- **Interfaz moderna**: Aplicación Flutter con temas Claro/Oscuro e integración en bandeja del sistema.

## 💻 Instalación

### Windows (x64)
1. Descarga el archivo `v2raypro-windows-v1.7.3.zip` desde [GitHub Releases](https://github.com/iamcloner/v2raypro/releases).
2. Descomprime el archivo zip en el directorio deseado.
3. Ejecuta `v2raypro.exe` (como Administrador si utilizas el modo TUN).

### Versión para Android
> 📱 **Nota**: La **versión para Android** se encuentra en desarrollo activo y estará disponible próximamente en [GitHub Releases](https://github.com/iamcloner/v2raypro/releases).
